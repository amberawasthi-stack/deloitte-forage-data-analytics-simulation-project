# deloitte-forage-data-analytics-simulation-project

## Project Overview
This repository contains my solutions for the Deloitte Data Analytics Virtual Experience Program on Forage.

The project involved analyzing manufacturing and workplace equality data using Tableau and Microsoft Excel to generate business insights and recommendations.

## Task 1: Machine Health Dashboard (Tableau)

### Objective
Analyze machine health data across factories and device types to identify areas requiring maintenance attention.

### Key Insights
- Daikibo Factory Seiko reported the highest number of unhealthy devices.
- Daikibo Shenzhen reported the second-highest number of unhealthy devices.
- Laser Welders and Laser Cutters showed the highest concentration of issues.

### Tools Used
- Tableau
- Data Visualization
- Business Analytics

## Task 2: Equality Score Analysis (Excel)

### Objective
Analyze equality scores across factories and job roles to identify potential workplace discrimination.

### Key Insights
- Several management-level roles were classified as Highly Discriminative.
- Some factories showed more equality concerns than others.
- The analysis helped identify areas where workplace policies may require review.

### Tools Used
- Microsoft Excel
- Data Analysis
- Data Classification
